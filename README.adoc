== 原型评审建议

平台管理员进入系统 A → 新建业务角色 → 授予 menu:audit 与 sys:audit:read → 给陈雨指派该角色 → 点击切换身份，以陈雨进入系统 A → 查看审计入口 → 管理员撤销后再次检查。切换身份时不要刷新，否则模拟变更会重置。

菜单权限和操作权限独立；只授予菜单不会自动授予接口操作权。日期筛选必须成对，最多 90 个自然日；空日期按近 7 个自然日查询。

== 维护与验证

Python生成脚本只使用标准库。先运行scripts/build_package.py生成契约、SQL种子、字典和阅读版；如修改原型源，进入prototype/vue执行npm ci与npm run build；进入scripts执行npm ci安装标准契约校验器，然后运行scripts/validate_openapi.cjs、check_browser.cjs、check_vue_browser.cjs；再运行verify_package.py检查一致性，最后package_delivery.py生成ZIP。浏览器脚本本机默认使用工作区运行时Playwright和Edge；迁移电脑需修改脚本的工具路径。构建依赖的初次安装需要网络，dist可离线打开。

生成文件以 scripts/contract.py 和 scripts/build_package.py 中的定义为源，不直接修改生成的 JSON、CSV、种子或 HTML 阅读版。编辑 .adoc 后需重建阅读版。
