= 多系统 RBAC0 权限管理系统
:toc:

本项目基于多系统隔离的 RBAC0：全局账号、系统成员、角色、权限、直接授权、会话与审计。不包含角色继承、互斥、人数限制、先决角色或角色子集激活。

== 第一次检查可运行成果

* `backend/`：Spring Boot 可运行后端，完成有效权限、动态菜单、统一鉴权、角色/权限/成员授权与审计。
* `prototype/`：独立 HTML 与 Vue 3/TypeScript 离线界面原型。
* `api/`：38 个端点的 OpenAPI 契约。
* `database/`：11 表 MySQL DDL、演示数据、后端演示口令与核对 SQL。
* `docs/`：需求、界面、API、数据库、详细设计、六人分工、验收与现场演示。
* `uml/`：用例、领域、组件、状态和 E 模块功能/流程/时序图。

== 启动后端

[source,powershell]
----
cd backend
.\mvnw.cmd spring-boot:run
----

打开 `http://localhost:8080/`。默认 H2 内存库自动初始化，演示账号密码均为 `DemoOnly12345`。

== 验证

[source,powershell]
----
cd backend
.\mvnw.cmd verify
----

自动化测试覆盖登录、越权 403、未登录 401、权限最小集、菜单投影、跨系统隔离和角色变更后的权限即时变化。JaCoCo 报告位于 `backend/target/site/jacoco/index.html`。
