== 设计方法

结构化主流程：参数解析→可信身份→范围策略→日期/筛选规范化→参数化查询→只读投影。写入由调用方事务持有，审计不自行提交。

面向对象：不可变AuditActor、AuditScope、AuditChange等封装不变量；AuditWriter、AuditRepository、SecurityEventRecorder和AuditIdentity通过端口协作，使用组合与依赖注入。

函数式：日期、脱敏、ID集合、快照差异使用无I/O纯函数，时钟由调用方传入；不修改传入JSON，不让纯函数处理数据库副作用。

== 验证与边界

Maven verify执行真实Java测试并生成JAR与JaCoCo。事务测试使用H2/JDBC，验证业务与成功审计共同回滚、安全事件独立提交。HTTP测试验证系统范围、可信身份、日期分页、脱敏、无写入路由及存储故障；浏览器脚本连接启动后的JAR，没有模拟API响应。

H2不是MySQL验收。非demo默认拒绝访问；A/E需要提供真正的会话验证、安全状态和实时权限，不能凭前端选择或自报请求头授权。A—E业务、Gitee/课程网站提交和服务器部署不在本次F实现完成范围内。
